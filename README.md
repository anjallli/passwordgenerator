# Password Generator 

## MSC CS Project

Password Generator is a Java Application developed to generate secure and customizable random passwords while helping users improve password security.
The application allows users to create passwords using combinations of uppercase letters, lowercase letters, numbers, and symbols based on their preferences and desired password length.

It also includes a password strength checker feature that analyzes the strength of a password based on factors such as character variety, symbols, numbers, and password length.
Additionally, the application provides useful password security tips and best practices to help users create safer and stronger passwords.

Tools & Technologies Used: Java, Eclipse/VS Code.
